# 小说审稿评分表（5 维 ×10 分）

只用于**同一本书内纵向比较**（这章比上章好还是差），不是发布门槛。
发布门槛只有一条：`deai_audit` 的 `counts.blocking === 0`。

## 1. 开篇拉力（0–10）

| 分 | 表现 |
| --- | --- |
| 0–2 | 开篇是天气、环境、身世介绍；300 字内没有任何异常 |
| 3–5 | 有事件但慢；第一段在铺垫，第二段才进事 |
| 6–8 | 300 字内出现一个具体的“不对劲”，读者知道该关心什么 |
| 9–10 | 第一句就不对劲，且这个不对劲直接连到本章主线 |

自检问题：把开头 300 字单独发给一个没看过前文的人，他会不会想知道下一句？

## 2. 场面具体度（0–10）

| 分 | 表现 |
| --- | --- |
| 0–2 | 只有情绪和判断，没有可拍的东西 |
| 3–5 | 有人物动作，但动作是通用的（走、看、说） |
| 6–8 | 至少一个只属于这个场景的细节（物件、声音、气味、手上的小动作） |
| 9–10 | 细节参与情节：一个物件同时承担信息、情绪和转折 |

自检问题：这一章你能挑出一个“只有这本书才会有的画面”吗？

## 3. 人物行为（0–10）

| 分 | 表现 |
| --- | --- |
| 0–2 | 人物按作者需要的方向行动，没有动机 |
| 3–5 | 动机说得通，但选择没有代价 |
| 6–8 | 有一个有代价的选择（放弃、得罪、暴露、违背原则） |
| 9–10 | 选择违反读者预期但完全可信；选择之后世界真的变了 |

自检问题：主角这一章放弃/付出了什么？想不出来就是没有选择。

## 4. 节奏（0–10）

| 分 | 表现 |
| --- | --- |
| 0–2 | 大段说明、回忆、设定，事件密度接近 0 |
| 3–5 | 事件够但平均：每段一样长、一样满 |
| 6–8 | 一段一件事，长短句交替，紧张处句子变短 |
| 9–10 | 节奏跟着情绪走：该快的地方几乎一句一段，该停的地方给足空间 |

自检问题：有没有哪一段可以整段删掉，情节不受影响？

## 5. 语言干净度（0–10）

| 分 | 表现 |
| --- | --- |
| 0–2 | `blocking` ≥5；情绪全靠判词；比喻是重锤、惊雷 |
| 3–5 | `blocking` 1–4；有若干套话但整体能读 |
| 6–8 | `blocking` = 0；`advisory` ≤8 |
| 9–10 | `blocking` = 0；`advisory` ≤3；有至少一句能被单独摘出来引用的好句子 |

自检问题：`deai_audit` 跑完，`counts.blocking` 是多少？

## 总分怎么用

- 不需要每章都打分；只在改稿前后各打一次，看有没有变好。
- 分低但 blocking=0，说明是结构问题（节奏/动机），不是语言问题——别去改词。
- 分高（≥35）且 blocking>0，先清 blocking，再看总分。

## 不要做的

- 不要跨书比总分（男频和女频、快节奏和慢热不能用一把尺子）。
- 不要为了拉分删事实、删对话、把人物写成完人。
- 不要把“类型套路”当缺点（退婚、系统提示音、扮猪吃虎是品类约定，看执行）。
